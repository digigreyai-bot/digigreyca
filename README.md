# DigiGrey Digital Visionaries — Website Source Code

Full source export of the DigiGrey website from Lovable. Stack: **TanStack Start** (React 19 + Vite + SSR) with Tailwind CSS v4, Framer Motion, and a Supabase (Lovable Cloud) backend.

## What's in here

- **`src/components/DigiGreyLanding.tsx`** — the entire one-page site (nav, hero, services, why-us, results, testimonials, process, contact form, footer). This is the file you'll edit most.
- **`src/routes/`** — TanStack Start file-based routing. `index.tsx` renders the landing page; `__root.tsx` is the HTML shell + SEO/meta tags.
- **`src/lib/consultation.functions.ts`** — the server function behind the consultation form: validates input, saves to Supabase, and emails `omar.far734@gmail.com` via Resend.
- **`src/integrations/supabase/`** — Supabase client setup (browser + server + auth middleware), auto-generated from the connected Supabase project.
- **`supabase/migrations/`** — the two SQL migrations that created the `consultation_submissions` table and its row-level-security policy.
- **`src/styles.css`** — the entire DigiGrey design system as CSS variables: brand purple (`#7B2D8B`), deep purple (`#4A0E6E`), vivid accent (`#9B30BE`), the gradient, shadows, and the network-pattern background utility.
- **`src/assets/digigrey-logo.png`** — the actual logo file.
- Root config: `package.json`, `vite.config.ts`, `tsconfig.json`, `eslint.config.js`, `.prettierrc`, `components.json` (shadcn config), `bun.lock`.

## About `src/components/ui/`

The project template ships with the full shadcn/ui component library (~44 primitives: button, dialog, select, tabs, etc.). **The DigiGrey site itself doesn't use any of them** — confirmed by grep, zero imports from `@/components/ui` anywhere in the live site code. Only `button.tsx` is included here as a reference sample.

If you ever need the rest (e.g. building an admin panel or a second page later), regenerate them in one shot:
```bash
npx shadcn@latest add accordion alert-dialog alert aspect-ratio avatar badge breadcrumb calendar card carousel chart checkbox collapsible command context-menu dialog drawer dropdown-menu form hover-card input-otp input label menubar navigation-menu pagination popover progress radio-group resizable scroll-area select separator sheet sidebar skeleton slider sonner switch table tabs textarea toggle-group toggle tooltip
```
This produces byte-identical files to what shipped originally, since they're unmodified stock components.

## Getting it running locally

```bash
npm install          # or: bun install (bun.lock is included)
npm run dev           # starts the dev server
npm run build          # production build
```

## Environment variables

Copy `.env` as-is for local dev — it already has the public Supabase URL and publishable (anon) key, which are safe to expose client-side.

**Not included (by design — these are secrets):**
- `SUPABASE_SERVICE_ROLE_KEY` — needed for server-side admin Supabase access
- `RESEND_API_KEY` — needed for the consultation form to actually send email

Both are managed as **Secrets** in the Lovable Cloud project dashboard, not as repo files. If you deploy this outside Lovable (e.g. Netlify), you'll need to add these as environment variables in that platform's dashboard — see the separate `DigiGrey_Deployment_Guide.md` for the full Netlify + custom domain walkthrough.

## Database

Two migrations create everything needed:
1. `20260710062245_...sql` — creates `consultation_submissions` table with open insert access

Run these against your Supabase project via the Supabase CLI or SQL editor if setting up a fresh backend outside Lovable Cloud.
